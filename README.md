**Employee Attrition Data Processing & Analysis**

A Python-based data processing project focused on cleaning, transforming, and analyzing employee data using Pandas, Matplotlib, and Seaborn.

**Key Features:**

* Imported and processed employee data from CSV files.
* Removed duplicate records using EmployeeID.
* Handled missing values and corrected data types.
* Converted date columns and standardized job titles.
* Performed string transformations and categorized employee experience.
* Filtered and aggregated data for year-wise workforce analysis.
* Created visualizations to explore employee trends and workforce patterns.

**Technologies:** Python, Pandas, Matplotlib, Seaborn



**Titanic Dataset Data Cleaning & Analysis**

A Python-based data analysis project focused on data cleaning, preprocessing, transformation, and exploratory analysis of the Titanic dataset using Pandas.

**Key Features:**

* Identified and handled missing values.
* Checked for duplicate records.
* Performed data transformation and string extraction.
* Created new columns and mapped or replaced values.
* Sorted and restructured datasets for analysis.
* Performed aggregation and correlation analysis.
* Used visualizations to explore relationships and patterns in the dataset.

**Technologies:** Python, Pandas, Matplotlib, Seaborn
